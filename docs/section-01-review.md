# 첫 화면 검토

상태: 구현 및 검수 완료, 사용자 검토 대기. 다음 섹션은 착수하지 않음.

- Figma 원본: 웹 1 `1:252`, 첫 화면 영역만 사용.
- 기존 입자 이미지 `1:254`: 로컬 원본, 90도 회전, 불투명도 60%, 하단 검정 그라디언트.
- POLARIS/Axis 제목, 번호별 문구 3개, 하단 소개 구현.
- 모바일은 설명을 한 영역에 모으고 좌우 문구를 그 아래에 배치.
- Higgsfield 생성과 Figma 수정은 수행하지 않음.
- 타입 검사와 Vite 프로덕션 빌드 통과.
- Chrome에서 1920, 1440, 390, 360px 확인: 가로 넘침 없음, 원본 이미지와 로컬 폰트 로딩 확인.
- Apple SD Gothic Neo가 없는 OS는 Arial/sans-serif를 사용하므로 글자 폭 차이가 있을 수 있음.
