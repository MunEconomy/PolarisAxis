# Polaris Axis 포트폴리오 제작 준비

작성일: 2026-10-04

## 현재 상태

- 저장소에 기존 코드, 브랜드 자료, 포트폴리오 콘텐츠가 없음.
- Figma와 Higgsfield 계정 인증 확인 완료. 개별 파일 접근과 생성 기능은 제작 단계에서 확인.
- 결과물은 웹사이트 중심으로 확정. Figma 설계와 Higgsfield 이미지·영상을 사용.
- 대상 독자, 브랜드 방향, 구현 기술과 호스팅은 미정.
- 아래 내용은 제작 제안이며 확정된 브랜드 정보가 아님.

## 도구별 역할 제안

| 도구 | 작업 | 산출물 |
| --- | --- | --- |
| Figma | 정보 구조, 스타일 탐색, 디자인 시스템, 화면 설계 | 편집 가능한 디자인 원본과 개발 기준 |
| Higgsfield | 키 비주얼, 프로젝트 이미지, 짧은 모션 | 선정된 이미지·영상 및 생성 기록 |
| 저장소 | 콘텐츠, 에셋 관리, 웹 구현을 선택한 경우 개발 | 제작 문서와 구현 파일 |

## 먼저 정할 내용

1. 형식: 웹사이트 중심으로 확정. 데스크톱·모바일 반응형 설계 제안.
2. 정체성: Polaris Axis가 개인, 팀, 스튜디오, 서비스 중 무엇인지와 한 문장 소개.
3. 대상과 목적: 채용, 클라이언트 문의, 협업 제안 등.
4. 대표 프로젝트: 프로젝트별 제목, 문제, 역할, 과정, 결과와 사용 가능한 이미지.
5. 표현 방향: 선호 레퍼런스, 로고, 색상, 한국어·영어 범위.
6. 작업 조건: 일정, Higgsfield 생성 예산, 기존 Figma 파일 유무.

## 콘텐츠 구조 초안

- 첫 화면: Polaris Axis 소개, 핵심 메시지, 대표 작업 진입.
- 대표 작업: 3~5개 프로젝트를 중심으로 선정.
- 프로젝트 상세: 배경 → 문제 → 역할 → 접근 → 결과. 성과 수치는 확인된 자료만 사용.
- 소개: 역량, 작업 방식, 구성원 또는 개인 소개.
- 연락: 사용자가 제공한 연락처와 링크.

## Figma 파일 구성 제안

- 00 Brief: 목적, 대상, 확정된 콘텐츠.
- 01 References: 레퍼런스와 스타일 탐색.
- 02 Foundations: 색상, 타이포그래피, 간격, 그리드.
- 03 Components: 내비게이션, 버튼, 프로젝트 카드, 섹션.
- 04 Screens: 선택한 형식의 완성 화면. 웹사이트라면 데스크톱·모바일 포함.
- 05 Handoff: 에셋, 인터랙션, 구현 기준.

## Higgsfield 에셋 준비

| 에셋 후보 | 먼저 필요한 정보 | 검수 기준 |
| --- | --- | --- |
| 대표 키 비주얼 | 브랜드 메시지, 분위기, 화면에서의 배치 | 브랜드 적합성, 텍스트 가독성 |
| 프로젝트 커버 | 실제 작업 자료와 프로젝트 설명 | 실제 작업과 일치, 시리즈 일관성 |
| 선택적 짧은 모션 | 정지 이미지 방향, 용도, 길이 | 움직임 품질, 로딩 부담, 정지 대체 이미지 |

생성 전 모델 조건과 비용을 조회하고, 선택한 방향을 소수 시안으로 검토한 뒤 확장한다. 생성 이미지는 실제 프로젝트 결과물과 혼동되지 않도록 용도를 기록한다. 로고와 화면 텍스트는 편집 가능한 요소로 관리한다.

## 제작 순서

1. 핵심 소개와 대표 프로젝트 자료 정리.
2. Figma에서 정보 구조 및 시각 방향 탐색.
3. 선택한 방향으로 Higgsfield 키 비주얼 시안 제작.
4. Figma 완성 화면과 컴포넌트 정리.
5. 선택한 결과물 형식으로 제작하고 화면·콘텐츠 검수.
