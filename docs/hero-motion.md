# 첫 화면 은하수 인터랙션

기존 Figma 배경 이미지를 화면에서 제거하고, 사용자가 제공한 화면 기록을 움직임의 참고로 사용합니다. 첫 섹션 전체를 실시간 Canvas 은하수로 채우며, 정적인 이미지 박스와 영상 재생 레이어는 사용하지 않습니다.

- 데스크톱: 2026-10-06 참고 영상에 맞춰 중앙 입자 구체의 위치는 유지하고, 커서 방향에 따라 yaw/pitch/roll과 하이라이트가 바뀝니다. 위치 이동은 좌우 최대 28px·상하 최대 20px로 제한합니다.
- 주변 별은 깊이에 따라 6~36px 시차로 반응하고, 커서 주변의 빛은 유체처럼 휘어지며 비스듬한 잔광을 남깁니다. 반복 원형 파동은 제거했습니다.
- 커서 이탈 시 자세와 조명이 부드럽게 중립으로 돌아옵니다. 배경 유체는 반해상도(최대 960×640)로 그린 뒤 합성합니다.
- 터치 화면: 커서 추적 없이 은하수가 자동으로 움직입니다. 터치 스크롤을 방해하지 않습니다.
- 배경은 첫 섹션의 상하좌우를 모두 채우며, 제목·소개 문구 뒤에 놓입니다.
- PAUSE/PLAY 버튼으로 배경 움직임을 제어합니다. 모바일에서는 소개 문구 아래에 버튼 공간을 확보합니다.
- 동작 감소 설정에서는 Canvas를 정지 상태로 표시하고 모션 버튼을 숨깁니다.
- 화면 밖 또는 숨김 탭에서는 애니메이션을 중지합니다.
- 배경 구현에는 외부 이미지 전송이나 영상 생성이 필요하지 않습니다. 앞선 Higgsfield 영상 생성안은 이번 구현으로 대체합니다.
- 원본 참고 에셋은 저장소에 보존하지만 페이지와 단일 파일 미리보기에는 포함하지 않습니다.
- `npm run build`는 Chrome에서 직접 열 수 있는 `preview.html`을 갱신합니다. 폰트와 배경 인터랙션 코드가 파일에 포함됩니다.

Chrome 파일 실행 검수 완료: 1920·1440·390·360px의 배경 범위와 가로 넘침, 문구 및 버튼 겹침, 파일 직접 실행, 배경 프레임 변화, 중심 고정·기울기·하이라이트·중립 복귀, 일시정지/재개, 동작 감소 설정, WebGL 컨텍스트 복원, 그래픽 초기화 실패 시 2D 대체 렌더링. 실제 모바일 기기의 터치 동작은 별도 검수가 필요합니다.

타입 검사와 프로덕션 빌드 통과. 제공된 화면 기록은 로컬에서만 참고했으며, 새 배경은 이미지나 영상을 재생하지 않고 WebGL 입자로 렌더링합니다.
